# Events and reactions: acceptance of the first version

> Recorded before ADR 0003. Reactions, `maxDepth` and `causedBy*` were removed from the domain; rows 2 and 4 describe behaviour that no longer exists, and rows that rely on tasks need re-running against the kit.

Status as of 2026-10-06. Each row is one bullet of "Acceptance for the first version" in `docs/EVENTS.md`. "Live" means shown on the pilot; the scripts are in `scripts/events-acceptance/` (run from the repository root through the SSH tunnel to the domain proxy). "Tests" means the automated suites: domain 327, receiver 22, hub 143, agent kit 294, manager 92, rules tool 61, SDK 46, dashboard 46.

|---|---|---|---|
| 1 | A real pull request triggers one review, even when the webhook is delivered twice | Live through the public host (synthetic signed delivery), tests; a real GitHub pull request pending | A signed `pull_request opened` delivery posted twice to the receiver origin gave one published event (the second logged `duplicate`), one `pr-review-opened` firing and one `code.review` task whose origin is `{kind: reaction, depth: 0}`; the task was cancelled. ## Not yet proven

* A real GitHub pull request end to end (the repository webhook towards the receiver is the owner's to wire); Woodpecker's own webhook is enabled, but no pipeline run was observed here (first plan and apply run from CI).
* Real senders: issue tracker and Datadog webhooks.
* The QA agent's card, so `qa-on-ticket` can create tasks.
* The Windows developer runs the new kit with events off and is not on the dashboard's agent list.

## Rollbacks

Domain image `pilot-3` can go back to `pilot-1` only with the pre-upgrade database backups (the schema moved on). Developer and reviewer: set `PI_VERSION` / `REVIEWER_VERSION` / `SANDBOX_VERSION` back to `pilot-5` in their `.env` files and `docker compose up -d`; the compose files and env files from before are in the pilot directory `backups-pre-events`. Dashboard: restore `compose.yaml.bak-pre-events` and recreate the container (the previous image stays on the host). Windows developer: the previous code is in `C:\somework\agent-backup-pre-events`.
